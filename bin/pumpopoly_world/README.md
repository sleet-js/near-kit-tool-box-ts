# PUMPOPOLY_WORLD

world game bins.

both bins are calls — they need a signer.

---

#### EXAMPLES

```sh
# call: move the player one step
bun run bin/pumpopoly_world/pumpopoly_world_move_player.ts

# call: elite move
bun run bin/pumpopoly_world/pumpopoly_world_elite_move.ts
```

#### FLAGS

`--contract-id` is optional on both bins — it falls back to the
per-network default.

| bin                             | flags |
| ------------------------------- | ----- |
| `pumpopoly_world_move_player.ts` | —     |
| `pumpopoly_world_elite_move.ts`  | —     |
