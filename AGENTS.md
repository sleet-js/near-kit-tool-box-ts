# near-kit-tool-box

tool box for near kit with custom web client and reusable functions.

this repo is a part of near kit tool box project
- [TS tool box](https://github.com/sleet-js/near-kit-tool-box-ts) - this repo, the typescript tool box
- [RUST tool box](https://github.com/sleet-rs/near-kit-tool-box-rs) - the rust tool box
- [SKILLS](https://github.com/sleetplayground/near-kit-tool-box-skills) - the skill library

---

#### USING

two ways to use. you can use the fun and web package for building near dapps.

or you can use the fun and env package and create runable ts files for doing transactions or view only calls. the bin folder here already has bins you can run.

this project makes it easy to interact with near smart contracts in a clean way, if the contract you want to interact with is not yet suppored feel free to contribute.
